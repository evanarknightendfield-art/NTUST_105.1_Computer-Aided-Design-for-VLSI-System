# CodexParallelChain

以 ClaudeOpus55_v6 為底，最終只保留平行 SA band 分界的四相循環。最終量測全部取自 [final/summary.md](../../Testcases/results/CodexParallelChain/final/summary.md)，下列表格保留同輪參考與三種協定的區別。

## 診斷摘要與改動

依 WORK_STATE：ejection 搜尋耗時偏高、位移收益有限；SA 固定 band 邊界使跨界移動受限；toy 的 cap 修補受總位移預算限制。最終讓 band 分界按批次輪替，使原邊界兩側能輪流交由同一 worker 搜尋。沿用接受規則、溫度、工作量、同步頻率與預算。原碼差異為 annealer.cpp 與新增 sa_bands.hpp；測試保留邊界、合法性、cache 與固定工作量重現檢查。

## 試過沒用與未實作

- target windows 不相交 segment 批次平行化：總位移、逐筆最大與半預算收益未通過保留條件，已撤回。
- ejection 候選處理縮減：沒有足夠吞吐／品質改善，已撤回。
- cap deadline 取消與修復預算調整：逐筆最大與時間驗收未完整成立，兩輪均撤回。
- ejection 分 band 尚未完成 touched-set 隔離、跨界補做與 barrier cap 重驗，未保留；不能說成已測得無效。post-chain DP 原已平行。toy 問題尚未解決。

## 驗收判讀與限制

合法性 27/27、新 seed 16/16、L1/L2 均 PASS；L1 187.2 < 240 秒，L2 211.3 < 600 秒。27 筆額外步驟超時 0。雙條件 20/27 ≥ 19；最大 22/27、總位移 25/27。總位移 GM（÷ ChainDP）0.99946 ≤ 同輪 v6 0.99948。

HPWL 同總時間與預設協定，holdout、edge 四個平均比值均 ≤ 同輪 v6；範圍見下表，部分 seed 仍較差。fixed 的兩組比值均為 1.00000；此單執行緒協定不能代表平行 band 的效益。大設計各一次，不能當多 seed 品質結論。

逐筆最大相對 v6 的 Stage 1 執行間變動門檻，summary 未提供完整逐筆對照與變動界線，因此本報告不宣稱該條最終驗收已證實；整體最大 GM 也不能替代逐筆檢查。summary 未列 L1/L2 額外步驟明細，該部分僅有 WORK_STATE 的 B 階段通過紀錄。

一般、ASan/UBSan、TSan 與固定次數重現檢查，WORK_STATE 記錄通過；沙箱 ASan 使用 detect_leaks=0，協調者已補跑外部 detect_leaks=1。本次不重跑測試，也不把歷史測試數字混入最終量測表。
