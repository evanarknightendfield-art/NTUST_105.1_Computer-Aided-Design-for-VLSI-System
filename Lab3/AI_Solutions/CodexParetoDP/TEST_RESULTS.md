# CodexParetoDP 實測結果

日期：2026-10-18（Asia/Taipei）。所有下列數字來自本次實際執行。

## 條件與通過項目

- 四版本均由相同 `g++ -std=c++17 -O2 -Wall -Wextra` 編譯，逐案循序執行。
- 使用 `--seed 1 --effort 200 --time 1000 --trace trace.csv -v`。這是本次測試參數，不是程式預設 effort=2000。
- v2 與新版本皆有 `minMoves=5000000`；相同測資的 SA 嘗試次數完全相同，且未觸及時間上限。
- v1 和 CodexGapSA 沒有此五百萬最低嘗試數，因此它們是功能／歷史基準，不宣稱與 v2 的 SA 次數相同。
- 新版本 11/11 PASS；連同其他版本，28/28 執行皆通過獨立 `check_pl.py`。
- 檢查兩階段的 row、site、subrow、重疊、fixed 位置、orientation，七個輸出檔，stdout 四項指標與 SA 不劣於 legal。
- 新增後處理各步的 HPWL 單調不增加；SA trace 的 best 單調不增，最終輸出與 polish trace 相符。
- 250 組 assignment／瓶頸指派與窮舉對照、100 組隨機 placement 性質測試通過 AddressSanitizer + UndefinedBehaviorSanitizer；未啟用 leak detection。
- 額外通過：完全被遮住的 row、全 fixed、無 net 設計、拒絕覆蓋輸入且輸入 SHA-256 不變。

## 原始紀錄與重跑

```bash
python3 tests/compare.py --effort 200 --time 1000
```

- `results/comparison/records.csv`：全部 28 筆結果。
- `results/comparison/settings.json`：編譯資訊、參數及各版本來源 SHA-256。
- `results/comparison/<版本>/<測資>/`：stdout、stderr、兩階段 placement、獨立檢查紀錄與 trace。
- `results/optimizer_test.log`：sanitizer 性質測試結果。
- `results/prototype/`：加入跨 row 搜尋前的第一輪比較表，保留開發過程數據。
- 修改新版本後使用 `--candidate-only` 重跑；腳本先確認基準參數與來源 hash 未改變，重用其已完成的執行。
- 自製 checker 並非教師官方評分器；本次沒有輸出三頁課程報告或學號繳交封裝。
