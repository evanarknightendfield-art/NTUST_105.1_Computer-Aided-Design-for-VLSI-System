# v3 — 模擬退火（Simulated Annealing）

> 第 5 課。把 v2 的 hill climbing 換成模擬退火：**偶爾接受變差**，跳出局部最佳。

## 編譯與執行

```bash
cmake -S . -B build
cmake --build build
./build/cbi INPUT_FILE OUTPUT_FILE
```

stdout 會印出 `T_max: X, T_min: Y, Score: Z`，stderr 會印出各階段的 `[stage1]`、`[stage2]` 紀錄。

## 測資說明

| 代號 | 資料夾 | 內容 |
|---|---|---|
| **測資 A** | `Lab2/Testcases/testcases/` | 課程 15 筆（001 = 範例，002–015 從 1 到 10000 個 sinks） |
| **測資 B** | `Lab2/Testcases/holdout/` | 報告用的新測資 12 筆（5 到 10000 個 sinks，`w_skew` 1～10） |

Score = buffer cost + w_skew × skew，**越低越好**。數字來自 `Lab2/Report/`（`run_everything.sh`），全部通過 TA verifier（VALID）。

## 和 v2 相比改了什麼

### 問題：Hill climbing 會卡住

```
Score
  │  ╲      ╱╲
  │   ╲    ╱  ╲        ╱
  │    ╲__╱    ╲      ╱
  │   局部最佳   ╲____╱  ← 真正更好的地方
  │   （卡在這）   全域最佳
  └──────────────────────→ 樹的形狀
```

要從左邊的坑走到右邊，**必須先往上爬（先變差）**，hill climbing 永遠不會這樣做。

### 解法：以機率接受變差

```
d = 新能量 − 舊能量
如果 d ≤ 0（沒變差）     → 一定接受
如果 d > 0（變差了 d）   → 以機率 e^(−d / 溫度) 接受
```

溫度從高慢慢降到低：前期大膽探索、跳出坑洞，後期幾乎只接受變好，收斂到附近最好的解。三種 move（Pad 20% / Shift 40% / Reparent 40%）和 v2 一樣。

### 四個重點

| 重點 | 做法 | 為什麼 |
|---|---|---|
| **溫度設定** | 起始溫度 T0 = f0 × c（c = 最便宜 buffer 的 cost，f0 隨 sink 數從 0.3 降到 0.03）；結束溫度 T1 = min(T0, 0.01 × min(c, w_skew))；`temp = T0 × (T1/T0)^(已用時間/總時間)` | 以「一個 buffer 的成本」當溫度單位；樹越大，起始溫度要越低；指數降溫讓收斂期夠長 |
| **能量多加 σ** | `energy = Score + 0.3 × w_skew × σ`（σ = 所有 sink arrival 的標準差） | skew 只看最大和最小，大部分 move 不會改變它，能量是平的；σ 讓每個 sink 變整齊都有回饋。**最後交出的仍是真正的 Score** |
| **記住最好的解** | 每 1024 次迭代檢查一次，有更好的就複製到 `best` | SA 會接受變差，結束時的樹不一定是最好的 |
| **小測資重啟** | N ≤ 50 時跑 4 次 × 1/4 時間，取最好 | 小測資 0.5 秒就收斂，換亂數種子多跑幾次比較穩定 |

重啟的效果（A-001 各跑 6 次）：

| 方式 | 6 次結果 | 平均 |
|---|---|---:|
| 單次 2 秒 | 39 37 46 49 47 41 | 43.2 |
| **4 次 × 0.5 秒取最好** | 42 40 37 43 38 37 | **39.5** |

### 參數實驗（測資 A，和最終設定的分數比值，越低越好）

| 設定 | 比值 | 結論 |
|---|---:|---|
| **最終版**（σ 權重 0.3、原本的起始溫度） | 1.000 | 採用 |
| 不加 σ（權重 0） | 1.030 | 差 3%，σ 有幫助 |
| 起始溫度 × 0.3 | 1.042 | 差 4%，太冷跳不出坑 |
| 所有測資都重啟 | 1.004 | 中型測資變差，所以只在 N ≤ 50 時重啟 |

## 觀察

- **整體再好約 17%：** 幾何平均比值 A 為 **0.826**、B 為 **0.842**。
- **小、中型測資進步最多：** A-003 從 318 降到 163、A-006 從 2208 降到 1399、A-015 從 113 降到 57，都是 hill climbing 卡住、退火跳出來的例子。
- **大測資幾乎沒進步，甚至變差：** A-007、A-011、A-013 都略差（+0.2～4.1%）。原因是**速度**：每試一次修改都用 `quickScore` 重算整棵樹（O(N)），1 萬個 sinks 時 20 秒只能試約 171 萬次，退火需要大量嘗試才能發揮作用。下一版 v4 用增量計算解決。
- **有隨機性：** 每次跑的分數會差幾 %，小測資尤其明顯。
